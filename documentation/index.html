Introducción

El Dashboard de Seguridad Ciudadana para San Juan de Lurigancho es una aplicación web interactiva diseñada para visualizar y analizar datos sobre casos de robos en el distrito más poblado del Perú. Esta herramienta tecnológica tiene como objetivo principal proporcionar información clara, accesible y actualizada que permita a los ciudadanos identificar zonas seguras e inseguras, facilitando la toma de decisiones informadas sobre sus desplazamientos.

Contexto del Proyecto

San Juan de Lurigancho enfrenta un grave problema de inseguridad ciudadana, con un aumento constante de delitos como robos, asaltos y actos de violencia. La falta de información centralizada y accesible dificulta que los ciudadanos tomen decisiones informadas sobre su seguridad personal.

Este proyecto se alinea con el Objetivo de Desarrollo Sostenible (ODS) n.º 9: Industria, innovación e infraestructura, promoviendo el uso de tecnología e innovación digital para fortalecer la seguridad ciudadana.

Presentación del Software

El software desarrollado es un dashboard web interactivo que centraliza, analiza y visualiza información sobre casos de robos en San Juan de Lurigancho. La aplicación proporciona una interfaz intuitiva que combina mapas georreferenciados, gráficos estadísticos y herramientas de filtrado para ofrecer una experiencia completa al usuario.

Características Principales

  • Interfaz web responsive: Accesible desde cualquier dispositivo
  • Mapas interactivos: Visualización geográfica de casos de robos
  • Gráficos estadísticos: Análisis temporal y por categorías
  • Sistema de filtrado: Búsqueda por fechas, zonas y tipos de delito
  • Chatbot integrado: Asistente virtual para consultas
  • Calendario interactivo: Navegación por fechas específicas

Objetivos Alcanzados

  • Centralización de información dispersa sobre seguridad
  • Identificación de zonas de riesgo y zonas seguras
  • Empoderamiento ciudadano mediante información accesible
  • Apoyo a la toma de decisiones de autoridades locales
  • Promoción de una cultura de prevención

Origen de los Datos

La calidad y confiabilidad del dashboard dependen directamente de la fuente de los datos. Para este proyecto, se implementó un proceso riguroso de extracción, transformación y carga (ETL) desde fuentes oficiales.

Fuente Principal de Datos

Observatorio Nacional de Seguridad Ciudadana

La principal fuente de datos es el Observatorio Nacional de Seguridad Ciudadana, plataforma oficial que recopila y sistematiza información sobre delincuencia a nivel nacional.

Proceso de Extracción
  • Técnica: Web Scraping automatizado
  • Herramienta: Python con BeautifulSoup y Selenium
  • Frecuencia: Actualización mensual
  • Datos extraídos: 50,000 registros iniciales
  • Filtro aplicado: Solo delitos de robo en SJL
Proceso de Limpieza (ETL)
  1. Eliminación de duplicados y registros inconsistentes
  2. Normalización de formatos de fecha y hora
  3. Geocodificación de direcciones
  4. Categorización por tipo de robo
  5. Validación de coordenadas geográficas

Nota Importante

Para garantizar la privacidad y cumplir con la Ley de Protección de Datos Personales (Ley N.º 29733), todos los datos personales han sido anonimizados. Solo se muestran datos agregados y estadísticos que no permiten la identificación individual de personas.

Metodología de Trabajo

El equipo trabajó bajo la metodología Design Thinking, siguiendo las fases:

  1. Empatizar: Entendimiento profundo del problema y usuarios
  2. Definir: Síntesis de información y definición del problema
  3. Idear: Generación de soluciones creativas
  4. Prototipar: Construcción de versiones tangibles
  5. Evaluar: Pruebas y refinamiento continuo

Complementado con metodologías ágiles para el desarrollo técnico, permitiendo iteraciones rápidas y entrega incremental de valor.
